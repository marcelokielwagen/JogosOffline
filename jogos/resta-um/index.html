Como jogar

  • Toque em uma peça e depois no buraco vazio para onde ela vai pular.
  • A peça pula por cima de uma vizinha (para os lados, para cima ou para baixo) e a vizinha sai do tabuleiro.
  • Os buracos que piscam mostram para onde a peça escolhida pode ir.
  • Ganha quem deixar só uma peça. Se ela terminar no centro, é jogada de mestre!
  • Errou? Use o Desfazer quantas vezes quiser.
